The unit 2-sphere, in 3D

What the tool proves, drawn from its own Lean files. Nothing here is a sketch.

The numbers, checked in Lean

Metric: g = diag(1, sin²θ)
Γθφφ = −sinθ cosθ,  Γφθφ = cotθ
Ricci: Ric = g wherever sinθ ≠ 0
Scalar: 2 at θ = π/4
At θ = π/4: Γθφφ = −1/2, Γφθφ = 1

The tool itself: what runs

  • Metric.lean
    A metric is a signature and a bilinear form. No instances are registered, so nothing can silently bind the wrong norm.
  • LeviCivita.lean
    Flat constant-metric connection, with coordinate Riemann, Ricci, and scalar definitions.
  • SphereTestSpherical.lean
    Koszul symbols from the metric, proved equal to the standard spherical symbols. Ricci = g, scalar = 2.
  • GitHub Actions, on every push
    Installs Lean 4.36.0, fetches the Mathlib cache, builds the whole project, and fails on any sorry.

The deletion check

Delete the ΓΓ sum from the Riemann components and the build fails: Rθφθφ reads 0 = 1/2. The test cannot pass with a curvature pipeline that always returns zero.
